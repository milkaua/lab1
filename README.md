# IT Project Lab 🧪

Навчальний проєкт для виконання лабораторних робіт з курсу **«Управління IT-проєктами»**.

## Стек технологій

- [Vite](https://vitejs.dev/) — збірник та dev-сервер
- Vanilla JavaScript (ES Modules)
- CSS змінні + Google Fonts

---

## 🚀 Запуск проєкту

```bash
npm install
npm run dev
```
